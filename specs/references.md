# Referências — Raccoons World

Jogos e mundos virtuais que inspiram o projeto. Use esta lista como referência
de game design, interação social e minigames ao escrever specs.

## Referências principais

| Jogo | Link | O que observar |
|------|------|----------------|
| Mundo Gaturro | https://www.mundogaturro.com | Mundo social latino-americano, casas personalizáveis, minigames |
| Club Penguin | https://en.wikipedia.org/wiki/Club_Penguin | Salas temáticas, chat seguro, minigames, eventos sazonais, iglus |
| Box Critters | https://en.wikipedia.org/wiki/Box_Critters | Mundo social simples feito para web, salas, itens colecionáveis |
| Party Parrot World | https://www.partyparrotworld.com/ | Mundo social leve e moderno inspirado nos clássicos |
| Habbo | https://www.habbo.com | Visual isométrico, quartos criados pelo usuário, economia de mobílias |
